# 客户银行转出修复

## 目标

客户在 Portal 提交银行转出申请；Core 原子冻结本金和手续费并创建 `SUBMITTED` 操作，后台继续沿用审核、拒绝解冻、人工付款后填写银行参考号完成的现有流程。

## 最小实现

- 移除 Portal 的只读禁用参数，提交前增加当前密码和 TOTP 确认。
- 新增 Go 客户专用提交接口，校验客户会话、转出锁和二次认证，并使用现有签名 Core 客户端转发。
- 新增 Core 内部专用入口，复用 `OperationsService` 的收款人、渠道、手续费、幂等与冻结逻辑；不开放客户通用 `/operations` 写入。
- 不增加功能开关、数据库表或自动银行付款。

## 验证

先补 Portal、Go、Core 的失败测试，再做最小修改；运行专项测试、类型检查、i18n、API 测试和构建。发布与部署不在本次范围。
